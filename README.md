# AI Response Evaluation Portfolio

This repository contains structured evaluations of AI chatbot responses across different scenarios including factual accuracy, emotional tone, and bias.

## Evaluation Framework
Each evaluation follows this structure:
- Rating (Good / Okay / Bad)
- Issues Identified
- Why It’s Problematic
- Improved Response

## Skills Demonstrated
- Critical Thinking
- AI Response Evaluation
- Bias Detection
- Prompt Engineering
- Structured Feedback
